Cold Plunge Timer

How to use the tool

Set and control the timer

Use the duration slider to choose your own time, then press Start. Pause and Resume control the countdown; Reset returns it to the time you selected. The default setting is not a safety recommendation. Leave the water whenever you feel unwell, even if the timer is still running.

Use the breathing guide

Select Box Breathing and press Start Breathing to see its inhale, pause, exhale, pause pattern. Press Stop when you want to finish. Read the breathing guide for the steps.

Review your sessions

A completed countdown is added to Session History in your browser. Clear all removes the saved sessions from this device. No account is required.
